# HR Analytics – Employee Attrition Prediction Using Data Science

## 📌 Project Overview

HR Analytics is a Machine Learning-based project designed to predict employee attrition and help organizations understand workforce trends.

The application analyzes employee information, predicts attrition risk and provides HR insights through interactive dashboards.

## 🎯 Objectives

- Predict employee attrition using Machine Learning.
- Identify employees at risk of leaving.
- Analyze employee satisfaction and work-life balance.
- Generate actionable HR recommendations.
- Visualize workforce insights using Power BI.

## 🛠️ Technologies Used

- **Programming:** Python
- **Data Analysis:** Pandas, NumPy
- **Machine Learning:** Scikit-learn
- **Backend:** Flask
- **Database:** MySQL
- **Visualization:** Power BI
- **Frontend:** HTML, CSS, JavaScript

## ⭐ Key Features

### 1. Employee Module
- Employee self-assessment form.
- Employee information management.
- Attrition risk prediction.

### 2. HR Manager Module
- Employee analytics dashboard.
- Department-wise attrition analysis.
- Employee risk monitoring.
- HR recommendations.

### 3. Machine Learning Module
- Employee attrition prediction.
- Prediction probability.
- Risk classification: High, Medium and Low.

### 4. Power BI Dashboard
- Overall attrition analysis.
- Department-wise attrition.
- Job role analysis.
- Overtime analysis.
- Employee satisfaction insights.

## 🧠 Machine Learning

The project uses a Gradient Boosting classification model to predict employee attrition based on employee-related features.

The model generates attrition predictions and supports HR decision-making.

## ⚙️ Installation and Setup

### Step 1: Clone the repository

```bash
git clone https://github.com/shalinikalepaka/HR_Analytics_Employee_Attrition.git
```

### Step 2: Open the project directory

```bash
cd HR_Analytics_Employee_Attrition
```

### Step 3: Create a virtual environment

```bash
python -m venv venv
```

### Step 4: Activate the environment

```bash
venv\Scripts\activate
```

### Step 5: Install dependencies

```bash
pip install -r requirements.txt
```

### Step 6: Configure MySQL

- Create the required database.
- Execute the SQL schema.
- Configure database credentials securely using environment variables.

### Step 7: Run the application

```bash
python app.py
```

Open the localhost URL displayed in your terminal.
